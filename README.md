# 🚀 Projects

| Assignment | Project                             | Description                                                                                      |
| ---------- | ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| 1          | Car Price Prediction                | Predicts the resale value of used cars using regression algorithms.                              |
| 2          | Adult Census Income Classification  | Classifies whether an individual's annual income exceeds a specified threshold.                  |
| 3          | Cancer Classification               | Predicts whether a tumor is benign or malignant using medical diagnostic data.                   |
| 4          | CIFAR-10 Image Classification       | Image classification using Convolutional Neural Networks (CNNs).                                 |
| 5          | LFW Face Recognition                | Face recognition using the Labeled Faces in the Wild (LFW) dataset.                              |
| 6          | Lunar Lander                        | Reinforcement Learning agent trained to land a spacecraft safely.                                |
| 7          | Movie Recommendation System         | Content-based recommendation system for suggesting similar movies.                               |
| 8          | CartPole                            | Reinforcement Learning project for balancing a pole on a moving cart.                            |
| 9          | Amazon Quarterly Report RAG Chatbot | Retrieval-Augmented Generation chatbot for answering questions about Amazon's quarterly reports. |

# 💻 Getting Started

### Clone the repository

```bash
git clone https://github.com/<your-github-username>/AI-ML-Assignments.git
```

### Move into the repository

```bash
cd AI-ML-Assignments
```

### Navigate to any project folder

```bash
cd Car_Price_Prediction
```

### Install the required dependencies

```bash
pip install -r requirements.txt
```

Run the notebook or Python application according to the project's README.
